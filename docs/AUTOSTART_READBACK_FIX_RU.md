# Автозапуск 0.3.3 — нормализация XML и отдельные состояния

В исследованной задаче Windows заменила LogonTrigger.UserId с SID на имя той же
учётной записи и опустила Enabled=true, Hidden=false, RunOnlyIfNetworkAvailable=false.
R2/R3 ошибочно требовали буквального совпадения. Проверка после регистрации
отклоняла корректную задачу, та же проверка мешала откату, сохранение настроек
не выполнялось. Оставалась задача без квитанции завершённой регистрации.
Это ошибка Open Net, а не доказательство стороннего вмешательства или отказа UAC.

При диагностике задача существовала, была включена, содержала правильные EXE,
аргумент --autostart и рабочую папку. Текущий LastTaskResult=0x00041303 означает,
что задача ещё не выполнялась. Operational-история отключена; ход сообщённой
перезагрузки по ней подтвердить нельзя. Значок в трее не доказывает запуск задачи
или инструментов. Полные пути/идентификаторы остаются в частном локальном отчёте.

Проверка теперь сопоставляет имя с SID средствами Windows, применяет значения
схемы для отсутствующих полей и сравнивает длительности/пути по смыслу. Команда,
аргументы, владелец, единственное действие, триггер, питание, условия и повторы
остаются под проверкой. Ошибка называет конкретное поле. Отключение задачи
не делает её чужой, но исключает готовность к запуску.

Интерфейс разделяет сохранённое желание, наличие регистрации, включённость,
подтверждённую принадлежность, готовность, LastRunTime/LastTaskResult и собственную
запись попытки запуска инструментов. Успех регистрации/завершения оболочки
не подменяет запуск инструментов и доступность сети.

После отдельного согласия пользовательский выбор сохраняется до регистрации.
Отказ UAC/проверки не стирает его. Повторное сохранение может повторить
незавершённую регистрацию. Оставшаяся неподтверждённая задача не принимается молча.
Явное исправление показывает текущую и новую команды, требует подтверждения/UAC,
сначала сохраняет XML и связывает согласие с его хешем. Изменение задачи после
подтверждения блокирует замену. Чужой источник/владелец и дубли не перезаписываются.
Откат не переписывает задачу, если исходная операция ничего не изменила.

Тесты проверяют нормализованный XML, реальные изменения полей, отключённую задачу,
отсутствующую квитанцию, одобрение восстановления и сохранение намерения после
имитации отказа UAC. Частный настоящий XML проверяется отдельно только чтением.
Настоящую задачу при разработке не меняли и не запускали. Реальный вход Windows,
исправление через UAC и запуск сетевых инструментов остаются отдельным испытанием.

Для оставшейся регистрации R2: выйдите из старой оболочки через меню трея
(инструменты продолжат работать), запустите новую сборку из постоянной папки,
выберите нужные опции и сохраните. Если нужна проверка оставшейся задачи,
нажмите «Исправить автозапуск», сверьте старую и новую команды и подтвердите UAC.
До этого задача автоматически не заменяется. Проверьте готовность регистрации,
затем отдельно согласуйте испытание входа в Windows. Не удаляйте рабочую папку
приложения, на которую указывает задача.
