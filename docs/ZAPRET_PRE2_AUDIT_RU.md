# Аудит Zapret: v0.3.3 → 0.4.0-pre.2

Это первоначальный аудит. Последующие исправления и актуальные ограничения описаны в [проверке жизненного цикла](PRE2_PROCESS_LIFECYCLE_RU.md), включая отказ от списка версий TG и автоматической остановки общего драйвера.

## Что подтверждено

В журнале первого компьютера: ошибка проверки сертификата `NotTimeValid` при системной дате 2019 года, затем успешная установка Zapret 1.10.4, отказ проверки одной из стратегий с сообщением про 1.10.3, последующие старты и отдельные ошибки проверки процесса Open Net. Эти события не доказывают единую причину. На втором компьютере 1.10.4 также установлена; журнал показывает создание процесса и остановки, но не содержит проверки доступности YouTube или конкретной причины недоступности.

Сравнение с `main` (v0.3.3): скачивание, извлечение аргументов BAT, проверка процесса родительской оболочки и повышенный помощник в основе совпадают с pre.1; строки о 1.10.3 существовали в v0.3.3. Pre.1 добавил сохранение активной стратегии и модульные переключатели. Одного изменения между версиями, которое доказанно вызвало все наблюдаемые ошибки, по журналам не установлено.

Официальные архивы 1.10.3 и 1.10.4 обработаны только в изолированном тестовом каталоге: последовательная установка, переход, манифест и ALT13 проверены без запуска бинарных файлов. 1.10.4 ALT13 проходит текущий разбор при корректном манифесте. Какой именно BAT и манифест были на первом ноутбуке в момент отказа, из журнала не следует.

## Изменения и границы

- Установка проверяет совместимость ALT13 до замены установленного модуля. При наличии манифеста BAT обязан совпасть с ним; совпадение с известным хешем другой версии не обходит эту проверку. Старый выбор пользователя автоматически не заменяется.
- Получение идентичности самой оболочки использует дескриптор текущего процесса, не требующий повторного открытия процесса с дополнительными правами. Это устраняет одну возможную причину отказа, но причины ошибки на конкретном ноутбуке без кода ошибки Windows не доказаны.
- При запуске проверяется идентичность созданного процесса; запуск EXE не объявляется проверкой YouTube и не записывает профиль как гарантированно работающий.
- Внешний процесс можно остановить индивидуальным переключателем только после подтверждения, когда найден ровно один экземпляр выбранной установленной и проверенной копии. Повторно проверяются PID, время старта, путь, хеш и отсутствие принадлежности службе; при несоответствии действие блокируется. Для Zapret стандартный UAC обязателен; драйвер при остановке внешнего процесса не меняется. TG получает попытку штатного закрытия перед завершением процесса.
- Экземпляр как служба Windows автоматически не останавливается: программа сообщает об ограничении. Экземпляры из неподтверждённого каталога и несколько процессов автоматически не останавливаются. Полноценное управление службами остаётся открытым вопросом.
- Внешняя остановка дополнительно ограничена заранее проверенными хешами файлов Zapret и TG 1.11.1/1.11.3/1.11.4: один изменяемый манифест недостаточен для разрешения завершения. Новые версии могут устанавливаться по обычным правилам, но их внешнее завершение требует отдельной проверки и до неё заблокировано.
- После выхода оболочки старая запись о процессе сама по себе не считается доказательством владения: она доступна для изменения другим приложением. После нового запуска такой процесс отображается как внешний и требует подтверждения. Автоматическое безопасное восстановление владения пока не реализовано.
- Язык нового профиля выбирается по языку интерфейса Windows: русский для `ru`, английский для остальных. Существующие сохранённые языковые настройки сохраняются.

## Не подтверждено

Эти проверки не заменяют воспроизведение на чистых физических Windows 10 и Windows 11 с разрешёнными пользователем запусками WinDivert, UAC и проверкой сайта. Не проверены настоящая остановка внешней службы, реакция конкретного антивируса и доступность YouTube через выбранную стратегию. Владелец должен проверить кандидата на обоих проблемных компьютерах, прежде чем разрешить публикацию.
