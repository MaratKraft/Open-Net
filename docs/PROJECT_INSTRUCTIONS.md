# Persistent ChatGPT project instructions

Status: not saved to the ChatGPT project. Available tools can list local projects but cannot edit persistent project instructions; native desktop control is unavailable in this session. Repository rules are independently recorded in CONTRIBUTING.md and AGENTS.md.

In the existing **Open Net** ChatGPT project, open its project menu/settings and the project instructions field. Append the following text without removing existing instructions. Do not create a replacement project. See [official project documentation](https://learn.chatgpt.com/docs/projects?surface=app).

> Open Net разрабатывается через GitHub `MaratKraft/Open-Net`. GitHub является основным источником актуального исходного кода. Work-чат Open Net — Development отвечает за код, отдельные ветки, тестирование, коммиты и Pull Requests. Work-чат Open Net — GitHub & Releases отвечает за проверку и публикацию релизов. Изменения в main и выпуск новых версий выполняются только после одобрения пользователя. Публичные теги и релизные файлы не изменяются задним числом. Новые функции разрабатываются в отдельных feature-ветках, исправления — в fix-ветках. Не выполнять force push в main и не публиковать секреты, пользовательские данные или временные сборки.
