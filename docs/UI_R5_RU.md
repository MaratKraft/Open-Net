# R5: индивидуальные переключатели и общие исправления

Переключатели в главном окне управляют конкретным инструментом. Состояние читается из наблюдения процесса / проверенной DNS-сессии. При отмене или ошибке операция не оставляет ложного зелёного состояния. Во время операции повторное нажатие и главная кнопка заблокированы. Чужие процессы остаются чужими: их нельзя остановить без подтверждённого владения.

Группа перенесена в отдельный столбец «В группе» окна «Модули». Видимость, группа, запуск с Windows и фактическая работа независимы. Основные иконки имеют прежние области 28 DIP и промежутки 4 DIP; переключатель занимает 42×28 DIP, правая сетка — 106 DIP. Сохраняются компоновка C и перестановка шеститочечной ручкой; постоянная клавиатурная подсказка убрана, доступная клавиатурная перестановка сохранена.

Тихие вторичные кнопки получили горизонтальный padding 10 DIP; выбор профиля — 8 DIP. Общие настройки разделяют поведение, краткий статус автозапуска/компактное исправление, служебные кнопки, дополнительные данные и закреплённую нижнюю панель с версией. Технический отчёт ограничен отдельной областью 140 DIP и записывается в журнал. Исправление регистрации использует прежний проверенный механизм согласия/UAC, при открытии ничего не регистрирует.

Старые квитанции Zapret без Profile честно показывают неизвестную активную стратегию. Новые запуски сохраняют реально запущенный профиль в квитанции; выбранная следующая стратегия не подменяет работающую. Длинные названия сокращаются, полное содержимое доступно в подсказке.

Проверки: 90 headless, 111 UI, все успешны. Только собственные заглушки, fake DNS и изолированное хранилище регистрации. RU/EN, dark/light, отрисовка 100/125/150%, прежние проверки материалов, фокуса, динамической высоты и сохранения порядка. Физический DPI, реальный UAC и настоящие DNS не проверялись. Локальный restore сообщает NU1900: аудит уязвимостей недоступен из ограниченного окружения.

Настоящие Zapret/TG, DNS/DoH/cache, маршруты, firewall и адаптеры не изменялись. Прежняя DNS-архитектура остаётся в этой ветке. Эксперимент создаётся отдельной веткой только после фиксации и проверки R5.
