# Open Net v0.3.2 Stable

A minimal Windows manager for Zapret and TG WS Proxy, now with a compact interface and Light, Dark and System themes.

## Download

- **[Standard EXE — recommended](https://github.com/MaratKraft/Open-Net/releases/download/v0.3.2/Open-Net-0.3.2-Windows-x64.exe)** — download and run; data stays in LocalAppData.
- **[Portable ZIP](https://github.com/MaratKraft/Open-Net/releases/download/v0.3.2/Open-Net-0.3.2-Windows-x64-Portable.zip)** — extract the whole folder and run `Open Net.exe`; data stays beside it.

## What's New

- Compact tool rows with consistent Download/Refresh, Settings and Select controls.
- Light and Dark themes, plus automatic following of the Windows system theme.
- Approved compact icon variant A and updated Zapret/TG WS Proxy module symbols.
- Mica/Acrylic improvements and fixes to visual alignment, switches and contrast.

## Installation

Windows 10/11 x64. Standard is a standalone application EXE. For Portable, keep `portable.flag` and move the entire folder after stopping tools and exiting. Do not run the EXE inside the ZIP. No separate .NET/Python installation is needed.

**Important:** Zapret and TG WS Proxy are not bundled. Use the download arrow in Open Net to install official components; compatible component updates remain independent of the shell.

## Known Limitations

The EXE is unsigned. Real Windows 10, physical monitor/DPI setups, live network/UAC behavior and startup after Windows sign-in still require target-machine checks. Network results and GitHub downloads depend on the environment; unknown offline imports require a verified official catalog. See the full validation document below.
