# Open Net v0.4.0-pre.2 — notes for personal testing

## Русский

Предварительный тестовый кандидат включает DNS Manager, модульную рабочую область и исправления установки и управления Zapret. Open Net проверяет формат ALT13 до установки официального архива; статус процесса не гарантирует доступность сайтов. Язык при первом запуске следует языку интерфейса Windows, ранее сохранённый выбор сохраняется.

Внешний экземпляр из выбранной проверенной установки можно попытаться остановить индивидуальным переключателем после подтверждения. Неоднозначные и неподтверждённые процессы и процессы-службы не останавливаются автоматически. Выключение DNS Manager возвращает автоматический IPv4 DNS.

Автоматическая установка обновлений Open Net и очистка старых версий модулей не включены. Фактические испытания на проблемных ноутбуках и проверка публикации необходимы до выпуска. Pre-release 1 не публиковался.

## English

This personal-test candidate includes DNS Manager, the modular workspace, and Zapret installation and process-management fixes. The official archive's ALT13 format is checked before installation; a running process does not prove website availability. A first-run language follows the Windows UI language; saved choices are retained.

The individual switch can request stopping one externally started process from the selected verified installation after confirmation. Ambiguous, unverified, and service-managed processes are not automatically stopped. Turning DNS Manager off restores automatic IPv4 DNS.

Automatic application installation and old-module cleanup are not included. Real testing on affected laptops and release review remain necessary. Pre-release 1 was not published.
