# Open Net 0.4.0 Alpha — UI-доводка R3

Работа поверх R2 в существующей DNS-ветке и Draft PR №2. Утверждены: вторичная нейтральная pill-кнопка «Модули» справа, строковое представление модулей, заполненный круг раскрытия. Плитки не включены. Порядок профиль → обновление → настройки → галочка, геометрия прежних иконок, области 28 DIP и интервалы 4 DIP сохранены.

Просмотрены все семь файлов из предоставленной папки OpenNet_UI_feedback_20261024: окно модулей, два выбора оформления, подпись главной кнопки, тесная кнопка DNS, обрезанный текст сохранения порядка и ссылка модулей.

## Исправления

- «Модули» имеет подложку ButtonSurface, минимальную ширину 104 DIP, внутренние отступы и маленькую заполненную пиктограмму справа. Остальные элементы нижней панели остаются на прежних местах.
- Назначение главной кнопки, раскрываемые разделы DNS и меню других действий используют одну векторную геометрию: заполненный круг 14 DIP и скруглённый chevron. Поворот отражает открытие. Компактные меню профилей сохраняют маленький chevron.
- Стандартный focus visual заменён общим скруглённым контуром. У прокручиваемых контейнеров нет рамки вокруг содержимого; прежние собственные индикаторы кнопок и переключателей сохранены. Клавиатурная навигация остаётся доступной.
- Цвет задан непосредственно в текстовых представлениях кнопок, ComboBoxItem и заголовков меню. Проверяется фактический TextBlock открытого popup, а не только Foreground родительского ComboBox.
- Закрытый ComboBox получил более свободный вертикальный отступ при прежней высоте.
- Внизу «Модулей» действия разнесены по настоящим строкам Grid, вместо наложения элементов с большим Margin. «Сохранить порядок» имеет автоматическую ширину с минимумом 160 DIP. Высота этих кнопок 36 DIP, вертикальные отступы 4 DIP.
- «Другие действия» имеет высоту 32 DIP, минимум 150 DIP, отступы 12×4 DIP и внешний зазор сверху/снизу.
- Добавлен отсутствовавший перевод Installed. Версия в настройках по-прежнему берётся из метаданных.

Перестановка остаётся в окне модулей за шеститочечную ручку, с отменой/сохранением и клавиатурной альтернативой. Стрелочные кнопки и прямое перетаскивание основной иконки не добавлены. Сохраняется восстановление живых вторичных окон после трея/минимизации. DNS остаётся простым: одна кнопка питания, автоматическая исходная копия и спокойное пояснение о возврате прежних параметров.

## Проверка

85 headless-проверок успешно. Успешный полный интерактивный прогон: 99 UI/stub-проверок, 0 ошибок. Новая проверка покрывает обе темы, цвет реального текста в раскрытом DNS-профиле, общие стили клавиатурного фокуса, размер «Других действий» и фактическое вмещение русского «Сохранить порядок» по метрикам шрифта. Получены WPF-снимки главного окна, нижней панели, настроек, модулей, перестановки и DNS.

Первый интерактивный прогон дал два непостоянных сбоя прежних тестов материала окна и клавиатурной активации логотипа. Для них добавлены подробные значения в сообщение ошибки; полный повтор прошёл без сбоев. Изменение поведения материалов или логотипа не заявляется как отдельное исправление этого прохода.

Сохраняются проверки R2: 1/2/3 модуля без лишней прокрутки в Auto, ручная минимальная высота с отдельным зазором ползунка, числовая сортировка ALT, темы, геометрия действий, восстановление вторичных окон, сохранение порядка, mock-применение и точное восстановление DNS. Масштабы 100/125/150% проверены WPF-отрисовкой; физические мониторы/DPI не переключались.

Тесты используют mock-адаптеры и собственные безопасные заглушки. Настоящие DNS, DoH, кэш, адаптеры, маршруты, Zapret и TG не менялись. Отдельные Standard/Portable/Safe Preview готовятся для личной проверки. Настоящий сетевой тест требует отдельного согласования. Merge и Release не выполняются.

При финальном повторе после исправления координат отдельного снимка нижней панели прошли 98 из 99 проверок. Единственная остановка — прежний тест Mica: защитная проверка Own foreground window only отказалась снимать окно, потерявшее фокус. Это ограничение воспроизводимости экранного теста, а не подтверждённая ошибка материала. Последний JSON с этой остановкой сохранён отдельно; предыдущий успешный полный JSON также сохранён. Новая проверка UI R3 в обоих прогонах прошла. Автоматическую проверку материала при фоновой работе нельзя считать стабильной.
