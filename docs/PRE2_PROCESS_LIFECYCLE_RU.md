# Проверка управления процессами pre.2

## Разрешённое реальное испытание 1 ноября 2026 года

Через интерфейс новой сборки проверено завершение существующего дерева TG v1.11.2 после подтверждения и UAC: Windows показала ноль процессов TG. Повторный запуск из Open Net создал новую пару родитель → ребёнок; оболочка продолжила считать её собственным работающим экземпляром после появления ребёнка.

При отсутствии winws и загруженном WinDivert из Zapret 1.10.4 выполнен разрешённый запуск ALT13. Процесс оставался живым, в выводе подтверждены инициализация WinDivert и начало захвата. После перезапуска оболочки тот же процесс найден как внешний и остановлен через точное подтверждение Zapret и UAC. Проверка Windows подтвердила отсутствие winws, сохранность обоих процессов TG и состояние WinDivert Running. Драйвер не выгружался. Доступность YouTube этим испытанием не установлена.

Общий текст подтверждения остановки собственного процесса ошибочно упоминал TG даже при выборе одного Zapret. Подтверждение теперь формируется из конкретного списка целей, а для Zapret явно сообщает о сохранении общего драйвера. Запуск и остановка реальных инструментов были отдельно разрешены пользователем.

## Исправления

Чтение пути EXE и времени создания использует PROCESS_QUERY_LIMITED_INFORMATION. Перечисление процессов больше не требует чтения их модулей. TG проверяется по сохранённому манифесту и свежим HTTPS-метаданным соответствующего официального выпуска GitHub, включая SHA-256: список номеров версий для внешней остановки TG не применяется. Ошибка сети или отсутствие digest блокируют операцию; локальная запись не заменяет проверку официального источника.

Один родитель TG и его проверенные прямые дочерние процессы одного EXE распознаются как экземпляр. Два корня, неизвестные потомки и службы отклоняются. Проверка повышенного TG при отказе доступа и остановка выполняются разовыми помощниками через штатный UAC. Помощник повторно проверяет официальный файл, PID, время создания и состав дерева после подтверждения. До завершения удерживаются проверенные дескрипторы процессов; изменившийся состав блокирует принудительное завершение. Сначала отправляется штатное закрытие окна, затем завершаются только подтверждённые процессы, если они не вышли.

Старые неподтверждённые записи не восстанавливают статус «собственный» автоматически. После перезапуска оболочки управление возвращается через подтверждённый внешний экземпляр. Это сохраняющееся ограничение, а не автоматическое восстановление доказанного владения.

Загруженный WinDivert больше не блокирует запуск сам по себе. Наличие winws проверяется отдельно; в отсутствие winws приложение разрешает явный запуск и проверяет, что процесс не завершился сразу. Остановка Zapret закрывает его процесс, но не выполняет SCM Stop для общего драйвера. Владельцы открытых дескрипторов драйвера не определяются по одному состоянию службы. Конфликт драйвера или стратегии отражается в журнале вывода; запуск процесса не доказывает доступность YouTube.

## Что проверяется автоматически

Собственные тестовые процессы, повторный запуск дерева, отказ при изменённом составе и сохранность независимого процесса. Моделируются ошибки, повторное использование PID, отмена подтверждения и независимые экземпляры. Официальные архивы Zapret используются как данные для проверки установки и ALT13; настоящие бинарные файлы и драйверы в тестах не запускаются. Тестируются будущие номера TG и отказы при изменённом digest/источнике.

## Испытание на проблемных компьютерах

1. Сохранить данные и закрыть старую оболочку через трей, не заменяя файлы работающих инструментов.
2. Открыть кандидат и проверить фактические версии и состояния. После перезапуска оболочки старый процесс может требовать подтверждения как внешний.
3. Отдельно согласовать остановку именно дерева TG. Подтвердить запрос приложения и UAC, убедиться в завершении дерева, затем запустить TG повторно.
4. Отдельно согласовать запуск Zapret при имеющемся драйвере. Если процесс завершится, сохранить журнал вывода и код ошибки. Не очищать драйвер вручную вслепую.
5. Проверить YouTube в браузере независимо от статуса процесса. Не считать ALT13 универсальной стратегией для всех провайдеров.

Запуск настоящего WinDivert, остановка действующих TG/Zapret, UAC остановки и реальные Windows 10/11 на проблемных ноутбуках требуют личного испытания. Доступная локальная Windows и имитация не заменяют эти проверки. DNS и настройки адаптеров испытание не должно менять.
