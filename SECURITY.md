# Security policy

Open Net 0.3.1 is a beta. Security fixes will target the latest published version; there is no guaranteed response deadline.

Use **Security → Report a vulnerability** in this repository when private vulnerability reporting is enabled. Include the affected version, impact and minimal reproduction without live credentials. Do not post exploit details, proxy secrets, keys or personal logs in public issues.

If the private reporting button is unavailable, open an issue asking the maintainer to enable a private reporting channel, without disclosing sensitive details. Wait for that channel before sharing the report. No private contact address is currently advertised.

Open Net installs separately maintained upstream components. Report vulnerabilities in those components through their own security channels, and notify Open Net privately if its integration is affected. SHA-256 checks establish file integrity; they do not prove that software has no vulnerabilities.
