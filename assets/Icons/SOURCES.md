# UI vector sources

Approved compact variant A (2026-10-12): Download and Refresh use original Open Net stroked paths with 1.4 DIP rounded caps/joins in an 18 DIP viewport. Download has a short straight bar, without tray sidewalls. These new geometries are authored under the project MIT license; the retained upstream Fluent Download/Refresh files describe the preceding implementation. Settings retains the Fluent vector with a 15.8 DIP optical box and a small themed stroke adjustment. Select renders a 16 DIP circle.

The current Zapret.User.svg is the owner's second SVG, with rounded silhouette details and Play corners. WPF uses its visible compound path; the separate fill:none path is not drawn. The owner approved the complete variant A and the revised straight-bar Download after reviewing WPF previews in the existing Open Net layout.

Download, Refresh and Folder/Open: Microsoft Fluent UI System Icons, `20_regular`, revision `a347af95478f989038cccbf085978865264c048a`. Upstream: https://github.com/microsoft/fluentui-system-icons. License: MIT, copyright Microsoft Corporation; the complete license is included in `assets/Notices/Fluent-LICENSE.txt` and distributed with both builds. Settings uses the existing `Settings.Fluent.svg` from the same MIT collection. WPF uses the path data, normalized to a common icon box and colored from theme resources. Original small SVGs are retained here for provenance; no icon font/package dependency is added.

Telegram plane: the white plane path from the official `Logo.svg` in the logo archive linked by https://telegram.org/press (checked 2026-10-12). Archive URL: https://telegram.org/file/464001088/1/bI7AJLo7oX4.287931.zip/374fe3b0a59dc60005. Only the plane path is used; the circular background and fixed white fill are removed. Telegram permits logo use for illustrative/buttons purposes provided users understand that the project does not represent Telegram officially. This is brand-asset permission, not an MIT license or a claim that Telegram's logo is public domain.

Open Net is an independent project, not an official Telegram client and not endorsed by Telegram. The icon identifies the TG WS Proxy module only. Its original application/tray icons are not modified. The user-provided raster reference is not redistributed.

Zapret: `Zapret.User.svg` was supplied by the project owner. WPF uses its single path verbatim, with nonzero filling and a theme brush; no raster conversion, new dependency or silhouette editing. The owner explicitly chose this SVG after reviewing a separate independent-controller proposal; that proposal is not part of the application.

This SVG combines a Discord-like silhouette with a Play cutout. The Discord resemblance is a visual assessment, not a trademark clearance decision. Separate permission for this derivative has not been provided; the owner's choice does not establish Discord authorization.
